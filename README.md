# WebCraft 方块世界

一个运行在浏览器里的《我的世界》风格方块沙盒游戏（生存 + 创造）。

**在线试玩：<https://relx8947.github.io/webcraft/>**（建议使用电脑上的 Edge / Chrome，需要 WebGL2）

**多人联机：<https://gservice.site/webcraft/>** → 标题画面点 **多人游戏**，所有人进入同一个常驻的公共生存世界。

- 纯 JavaScript ES 模块 + WebGL2，**零依赖、无需构建**。
- 所有纹理、图标、生物皮肤、天空、声音和背景音乐都在运行时由程序生成，项目里没有任何图片或音频文件。
- 界面为简体中文。

> 这是一个致敬《我的世界》的同人作品，与 Mojang Studios 和 Microsoft 无关。

## 快速开始

需要 [Node.js](https://nodejs.org) 18 或更高版本（推荐 22），以及 Chrome / Edge 120+ 或 Firefox 120+。运行测试和 `tools/` 下的开发工具需要 Node.js 22 或更高版本（即 `package.json` 中 `engines` 声明的版本）。

- **Windows**：双击 `start.bat`。它会启动本地服务器并自动打开浏览器。
- **任意系统**：在项目目录运行：

  ```
  node server.js
  ```

  然后在浏览器中打开 <http://127.0.0.1:8080>。端口被占用时会自动换用下一个端口，请以终端输出为准。也可以用 `node server.js --open` 自动打开浏览器，或用 `PORT=9000 node server.js` 指定端口。

进入游戏后，依次点击 **单人游戏 → 创建新的世界**，填写名称和种子（可留空），选择 **生存 / 创造** 和 **默认 / 超平坦**，再点 **创建新的世界**。

点击画面可以锁定鼠标；按 **Esc** 打开游戏菜单（同时会保存世界）。世界每 30 秒自动保存，切换标签页、关闭页面或“保存并退出到标题画面”时也会保存。存档放在浏览器的 IndexedDB 中。

> 必须通过 `node server.js` 访问：直接双击 `index.html`（`file://` 协议）时，浏览器不允许加载 ES 模块和 Web Worker。

### 多人联机

标题画面的 **多人游戏** 会连接页面所在网站的联机服务器（公共服务器在 <https://gservice.site/webcraft/>）。输入名字就能进入一个所有人共享的生存世界：方块、箱子、熔炉、生物和时间都是同步的，背包和位置保存在服务器上。名字会绑定到第一次使用它的浏览器。按住 **Tab** 查看在线玩家，**T** 聊天。

自己搭服务器：

```
WEBCRAFT_STATIC=. WEBCRAFT_ADMIN_KEY=你的口令 node server/main.mjs
```

然后打开 <http://127.0.0.1:8787/>。在游戏里输入 `/login 你的口令` 成为管理员。服务器的配置、权限、校验规则和网络协议见 [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md)。

### 第一晚生存指南

1. 徒手撸树（按住左键）得到原木，按 **E** 打开物品栏，在 2×2 合成格里做木板，再做工作台。
2. 右键工作台，做木镐 → 挖圆石 → 做石镐、石剑和**熔炉**（8 个圆石围一圈）。
3. 太阳落山前用木棍 + 煤炭做火把，或者挖个洞把自己围起来。夜里会刷出**僵尸、骷髅、苦力怕和蜘蛛**。
4. 杀猪、牛、羊、鸡得到生肉，放进熔炉烤熟再吃（按住右键进食）。饥饿值只剩 3 格鸡腿或更少时就不能疾跑了。
5. 把铁矿石和煤放进熔炉，10 秒炼出一块铁锭；用 **箱子** 存放物品。
6. 用锄头开垦草地、种下小麦种子（拔草有几率掉落），附近有水的耕地长得更快，3 个小麦可以做面包。

物品栏、箱子和熔炉的操作和原版一致：

- **左键**：拿起或放下整组；**右键**：拿起一半或放下一个。
- **Shift + 左键**：快速移动（可熔炼的物品进熔炉上格，燃料进下格，箱子和背包之间互相移动）；在合成结果上使用时会一次合成尽可能多的物品。

- **悬停时按数字键**：与快捷栏交换。

## 主要功能

- **无限世界**：区块在后台 Web Worker 中生成和构建网格，随玩家移动流式加载和卸载。
- **地形生成**：受 1.18 启发，包含大陆、海洋、河流、沙滩和山脉（高至 200 格左右，带雪顶）。
  - 18 种生物群系：平原、森林、桦木森林、繁花森林、针叶林、积雪针叶林、雪原、沙漠、山地、雪峰、海洋、深海、冻洋、河流等。
  - 奶酪洞穴、意面洞穴、峡谷，地下深处有岩浆湖。
  - 矿石分布与原版相似：煤、铁、金、红石、钻石、青金石。
  - 植被：橡树、白桦、云杉、松树、仙人掌、甘蔗、花草、蘑菇、南瓜。
- **生物**（8 种，数值取自 Java 版）：
  - 被动生物：**猪、牛、羊、鸡**。会四处游荡、受伤后逃跑、躲开悬崖和岩浆；牛和羊会跟着手持小麦的玩家，鸡会跟着手持种子的玩家；羊会低头吃草，有白、黑、灰、棕、粉等天然毛色；鸡缓慢飘落。新生成的区块里约 10% 会有一群动物，动物不会消失，会随存档保存。
  - 敌对生物：**僵尸**（追击玩家、举起双臂攻击）、**骷髅**（保持距离、绕圈拉弓射箭）、**苦力怕**（靠近后嘶嘶作响、膨胀闪白，1.5 秒后爆炸，走远会中断）、**蜘蛛**（白天中立，黑暗中主动攻击、会爬墙、会扑跳，眼睛在夜里发光）。
  - 敌对生物在黑暗处生成（夜晚的地表、洞穴里），远离玩家后会消失；僵尸和骷髅在阳光下会着火，骷髅会躲进阴影。
  - 受伤红色闪烁、击退、无敌时间、倒地死亡动画和烟雾；掉落物与原版相同，着火时死亡掉落熟肉。生物会被水流冲走、会游泳、会摔伤，A* 寻路绕过障碍。
- **战斗**：工具伤害、下落暴击（×1.5，带暴击粒子）、疾跑击退、武器耐久；玩家受击退；中文死亡信息（例如“玩家被僵尸杀死了”“玩家被骷髅射杀”“玩家被苦力怕炸死了”）。
- **弓和箭**：按住右键拉弓（画面会拉近，弓有 3 个拉弦帧），松开射出带重力的箭；拉满时为暴击箭。箭会插在方块上，可以捡回来。
- **饥饿**：饥饿值、饱和度和消耗与原版一致（疾跑、跳跃、攻击、挖掘都会消耗）。饱食时回血；饥饿值为 0 时扣血：简单难度扣到 5 颗心，普通扣到半颗心，困难会饿死。和平模式下饥饿值不会下降并自动回血。腐肉、生鸡肉会造成饥饿效果，蜘蛛眼会中毒（心和鸡腿图标会变色）。
- **熔炉和箱子**：熔炉有燃料火焰和进度箭头，燃烧时方块变亮并冒烟；1 块煤炭可以烧 8 个物品，熔岩桶燃烧时间最长。箱子有 27 格。破坏或炸毁时里面的物品会掉出来；内容随存档保存。
- **流体**：水和岩浆会按原版规则流动（水每格降 1 级、流 7 格；岩浆流 3 格且更慢），优先流向最近的落差，形成瀑布；两格水源之间生成无限水源。岩浆遇水：岩浆源变成**黑曜石**，流动的岩浆变成**圆石**，岩浆流进水里变成石头，并伴随“嘶”声和烟雾。水会冲走火把、花草和庄稼。只能用桶舀起水源。
- **农业**：锄头开垦耕地；附近 4 格内有水时耕地会变湿（颜色变深）；小麦有 8 个生长阶段，光照需 ≥ 9，湿润耕地长得更快；成熟后收获小麦和种子。
- **方块规则**：火把可以插在墙上；失去支撑的方块会掉落（火把、花、甘蔗需要旁边有水、仙人掌旁边不能有方块）；砂砾和沙子在旁边方块变化时会下落；砍掉树干后，离原木太远的树叶会逐渐凋落并掉落树苗和苹果（玩家放置的树叶不会）。
- **画面**：
  - 平滑光照和环境光遮蔽；天空光与方块光（火把）分开计算；亮度曲线与原版一致（无火把的洞穴也能隐约看见），可以在选项中调节亮度。
  - 完整的昼夜循环：日出日落的霞光、星空、太阳和月亮、会飘动的 3D 云。
  - 距离雾，水下和岩浆中有专门的雾和色调；半透明的水、冰、玻璃按距离逐面排序，从任何方向看都正确。
  - 动态水面（流动的水面有坡度）和岩浆，随风摆动的草和树叶，按生物群系变化的草地和树叶颜色。
  - 第三人称视角可以看到玩家模型（拉弓、进食动作），生物都有原版比例的方块模型和动画。
- **合成**：2×2 和 3×3 合成，共 54 个配方（全部工具、锄头、弓、箭、箱子、熔炉、火把、面包、TNT 等），17 种熔炼。创造模式物品栏带分类标签（含“刷怪蛋”）和搜索。
- **声音**：程序合成的方块音效（按材质区分）、脚步声、各种生物的叫声 / 受伤声 / 死亡声、攻击和暴击声、弓弦声、箱子开关声、熔炉噼啪声、岩浆冒泡和流水声，以及安静稀疏的钢琴背景音乐。
- **存档**：存在 IndexedDB 中，只保存被修改过的区块（RLE 压缩），以及玩家、物品栏、时间、生物、掉落物、箭和箱子 / 熔炉的内容。
  - 每次保存都在**一个事务**里完成，关闭或刷新页面也不会丢失方块修改；有未保存的进度时关闭标签页会弹出确认。
  - 同一个世界只能在一个标签页中打开；保存失败时世界不会被关闭，可以重试或选择不保存退出。
  - 浏览器禁止本地存储时，标题画面会提示“世界不会被保存”。
- **设置**：渲染距离 2–16、视场角、鼠标灵敏度、反转鼠标、视角摇晃、平滑光照、云、音效和音乐音量、显示帧率、界面尺寸、全屏、**难度**（和平 / 简单 / 普通 / 困难）、**亮度**（昏暗 … 明亮）。

## 命令

在聊天栏（按 T 或 /）中输入。支持 `~` 相对坐标和 `^` 局部坐标，按 Tab 可以自动补全（中文也可以）。

| 命令 | 说明 |
|---|---|
| `/help [命令]` | 查看命令列表或某个命令的用法 |
| `/gamemode <survival\|creative>` | 切换生存 / 创造模式（别名 `/gm`） |
| `/time <set\|add\|query> <值>` | 设置或查询时间（`day` `noon` `night` `midnight`，或刻数、`5s`、`1d`） |
| `/tp <x> <y> <z> [水平角] [垂直角]` | 传送 |
| `/give <物品> [数量]` | 给予物品；可以用英文 ID 或中文名，例如 `/give 钻石镐`、`/give 僵尸刷怪蛋` |
| `/clear [物品] [数量]` | 清除物品栏 |
| `/summon <生物> [x y z]` | 召唤生物：`pig` `cow` `sheep` `chicken` `zombie` `skeleton` `creeper` `spider`，也可以用中文名，例如 `/summon 苦力怕 ~ ~ ~5` |
| `/kill [目标]` | 杀死玩家；`/kill @e` 杀死所有生物，`/kill @e[type=zombie]`、`/kill @e[type=!pig,distance=..10,limit=3]` 等选择器 |
| `/difficulty [难度]` | 查询或设置难度：`peaceful` `easy` `normal` `hard`（或 和平 / 简单 / 普通 / 困难）。和平模式会清除敌对生物 |
| `/seed` | 显示世界种子 |
| `/spawnpoint [x y z]` | 设置重生点（可以设在洞穴或房间里） |
| `/setworldspawn [x y z]` | 设置世界出生点 |
| `/setblock <x> <y> <z> <方块> [replace\|keep\|destroy]` | 放置一个方块 |
| `/fill <x1> <y1> <z1> <x2> <y2> <z2> <方块> [模式]` | 填充区域（最多 32768 个方块） |
| `/say <消息>`、`/me <动作>` | 聊天消息 |

## 调试与自动化

在网址后加参数可以直接进入一个临时世界，适合测试：

```
http://127.0.0.1:8080/?autostart=1&seed=42&mode=creative&type=flat&rd=8&time=noon&nomusic=1
```

| 参数 | 说明 |
|---|---|
| `autostart=1` | 直接创建并进入一个临时世界（默认不保存，加 `save=1` 才保存） |
| `seed` / `mode` / `type` | 种子、`survival` / `creative`、`default` / `flat` |
| `rd` | 本次的渲染距离（不会写入设置） |
| `time` | 时间：刻数，或 `noon`、`night`、`midnight` 等 |
| `nomusic=1` | 不播放背景音乐 |
| `automation=1` | 没有鼠标锁定时键鼠也可以操作（`autostart=1` 已自动开启） |

浏览器控制台中可以通过 `window.__game` 访问游戏对象，`window.__ready` 在出生区域加载并渲染完成后变为 `true`。`__game.debug` 提供以下方法：

- `tp`、`look`、`lookDeg`、`lookAt`
- `setTime`、`setBlock`、`getBlock`、`blockName`
- `give`、`setMode`、`select`
- `mine`、`use`、`target`、`findBiome`
- `summon(类型, 距离)`（在面前召唤生物）、`mobs()`（附近生物列表）、`clearMobs()`
- `waitIdle`、`frames`、`stats`、`perf`、`hideHud`

## 开发与测试

```
npm test                         # Node 单元测试（node --test "tests/*.test.js"），共 529 项（含联机服务器测试）
node tools/harness.mjs --url "index.html?autostart=1&seed=42" --wait-for "window.__ready" --screenshot tools/out/game.png
node tools/harness.mjs --url "index.html?autostart=1&seed=42" --wait-for "window.__ready" --steps tools/steps/w2-hostile.json
node tools/run-steps.mjs -j 3 tools/steps/w2-*.json      # 并行运行多个脚本并汇总结果
```

`tools/harness.mjs` 会用无头 Edge/Chrome（使用真实 GPU）打开页面。它可以截图、执行脚本、发送真实的键盘和鼠标事件；页面出现任何错误时退出码为 1。在 Git Bash 中，`--url` 不要以 `/` 开头。

`tools/steps/` 下是集成测试脚本：

- `integ-*.json`：行走、破坏和放置；通过界面创建世界；保存、退出、刷新页面后重新进入；合成；掉落与拾取；设置、死亡与重生；TNT；生物群系巡览；60 秒行走的性能测试。
- `w2-*.json`：每种生物的白天 / 夜晚 / 第三人称截图、僵尸追击、骷髅射箭、苦力怕爆炸、战斗与掉落、刷怪蛋和命令、进食与饥饿、弓箭、箱子存档、熔岩与水生成黑曜石、瀑布、耕种到面包、75 秒夜间生存、30+ 生物性能测试。
- `mobs-*`、`surv-*`、`containers-*`、`fluids-*`：各模块作者的测试脚本。

`tools/` 下的其他页面是各模块独立的可视化测试页（例如 `tools/mob-test.html` 生物模型、`tools/texture-preview.html` 纹理）。

## 已知限制

- 没有经验、盔甲、附魔、红石和下界；生物不会繁殖，没有剪刀（羊不能剪毛）、鸡不会下蛋。
- 僵尸不会破门；寻路不会使用梯子；非常宽的蜘蛛在 1 格宽的通道里可能会卡住。
- 箱子没有开盖动画，也没有大箱子；熔炉没有经验和配方书。
- 流动的水和岩浆使用静止的纹理（没有流动方向的纹理滚动）；岩浆不会点燃方块；没有下雨。
- 汉字使用系统字体，英文和数字使用程序生成的像素字体。
- 第一次点击时会创建音频引擎，可能有一次约 0.1 秒的卡顿。
- 在窗口模式下，浏览器会把 Ctrl+W 当作关闭标签页（游戏会先弹出确认并已保存）；建议用双击 W 疾跑，或者进入全屏。
