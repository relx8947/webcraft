# 多人联机

WebCraft 的多人模式是**一个常驻的公共世界**：服务器上只有一个世界，所有人通过标题画面的“多人游戏”进入同一个世界，方块、箱子、熔炉、生物、掉落物和时间都是共享的。

## 架构

```
浏览器（src/net/）                         专用服务器（server/，Node 22+，零依赖）
┌─────────────────────────┐   WebSocket   ┌──────────────────────────────────────┐
│ World 副本（remote 模式）│ ◄───────────► │ ServerGame：20 TPS 权威模拟           │
│  原始区块按种子本地生成   │  JSON + 二进制 │  World（多观察者流式加载，仅算光照）    │
│  修改过的区块由服务器发送 │               │  流体 / 方块更新 / 随机刻 / 熔炉        │
│ RemoteEntityManager      │               │  EntityManager + MobSpawner（每个玩家） │
│  实体副本 + 插值          │               │  RemotePlayer：玩家的服务端代理         │
│ 本地玩家（移动、生命、饥饿、│               │ Session：校验、限流、复制状态           │
│  物品栏由客户端模拟）      │               │ FileBackend：磁盘存档（原子写入）       │
└─────────────────────────┘               └──────────────────────────────────────┘
```

- **服务器是世界的权威**：方块修改、方块更新（沙子下落、火把掉落、流体）、熔炉、箱子、生物 AI 与生成、掉落物、箭、TNT 和爆炸都只在服务器上运行，结果复制给客户端。
- **客户端是自己玩家的权威**：移动、生命值、饥饿和物品栏由浏览器模拟（与单人模式同一套代码），服务器通过 `RemotePlayer` 镜像位置和物品栏，并把伤害、击退、拾取、传送等转发给客户端执行。
- 共享模块（`src/world/`、`src/game/`）对多人模式只有少量改动：`players.js` 让生物、箭、爆炸和拾取遍历所有玩家；`World` 增加 `remote`（客户端副本）、`setViewers`（服务器多观察者）和 `lightOnly`（服务器只算光照不建网格）。

## 运行

```
WEBCRAFT_STATIC=. WEBCRAFT_ADMIN_KEY=口令 node server/main.mjs
```

然后打开 <http://127.0.0.1:8787/>，点击 **多人游戏**。`WEBCRAFT_STATIC` 让服务器同时提供游戏页面（本地开发用）；正式部署时页面由 nginx 提供，只把 `/webcraft/ws` 和 `/webcraft/status` 反向代理到服务器。

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `WEBCRAFT_PORT` / `WEBCRAFT_HOST` | `8787` / `127.0.0.1` | 监听地址 |
| `WEBCRAFT_DATA` | `./data` | 存档目录（`<目录>/<世界>/meta.bin`、`chunks/`、`data/`） |
| `WEBCRAFT_WORLD` | `main` | 世界 ID |
| `WEBCRAFT_SEED` / `WEBCRAFT_WORLD_TYPE` | 随机 / `default` | 只在第一次创建世界时使用 |
| `WEBCRAFT_ADMIN_KEY` | 空（不能登录） | `/login <口令>` 成为管理员 |
| `WEBCRAFT_OPS` | 空 | 逗号分隔的管理员名字 |
| `WEBCRAFT_MAX_PLAYERS` | `20` | 最多同时在线人数 |
| `WEBCRAFT_SIM_DISTANCE` | `5` | 每个玩家周围模拟的区块半径（3–8） |
| `WEBCRAFT_ORIGINS` | gservice.site + localhost | 允许连接的页面来源（逗号分隔） |
| `WEBCRAFT_MOTD` | 空 | 进入时显示的欢迎语 |
| `WEBCRAFT_PVP` | 关 | `1` = 玩家的箭可以伤害其他玩家 |

服务器每分钟自动保存一次，收到 `SIGINT` / `SIGTERM` 时保存后退出。`GET /webcraft/status` 返回在线人数和玩家列表（标题画面的“多人游戏（N 人在线）”）。

## 玩家与权限

- **名字认领**：第一次用某个名字进入时，服务器生成一个随机令牌，保存在这个浏览器的 localStorage 里；以后只有带着这个令牌的浏览器才能使用这个名字。换了浏览器或清除了数据，可以请管理员 `/forget <名字>` 释放名字（背包和位置保留）。
- 玩家的位置、背包、生命值和重生点每 10 秒以及离开时保存在服务器上，下次进入时恢复。
- **普通玩家**可以用 `/help` `/list` `/me` `/seed` `/kill`（只能杀死自己）`/login`。其他命令（`/gamemode` `/give` `/tp` `/time` `/summon` `/setblock` `/fill` …）只有管理员能用。
- **管理员**：`/login <口令>`（服务器设置的 `WEBCRAFT_ADMIN_KEY`）或 `WEBCRAFT_OPS`。额外命令：

| 命令 | 说明 |
|---|---|
| `/op <玩家>`、`/deop <玩家>` | 设置 / 撤销管理员 |
| `/kick <玩家> [原因]` | 请出服务器 |
| `/ban <玩家> [原因] [--ip]`、`/unban <玩家\|ip:地址>` | 封禁名字（加 `--ip` 同时封禁 IP） |
| `/forget <名字>` | 释放名字认领（玩家不在线时） |
| `/tp <玩家> [玩家]` | 传送到玩家 / 把玩家传送到玩家 |
| `/gamemode <模式> <玩家>` | 设置其他玩家的游戏模式 |
| `/save`、`/status` | 立即保存；服务器状态（在线、实体、区块、最慢的刻） |

## 校验与限流

客户端发来的每条消息都要经过校验：

- **限流**（令牌桶）：消息 300 条/秒；方块修改 40 次/秒；聊天 1 条/秒（可连发 5 条）；命令 2 条/秒；生成实体 20 次/秒；攻击 10 次/秒。超出总消息限额会被断开。
- **方块修改**：距离（眼睛到方块中心 8 格内）；只允许玩家能放置的方块（流动的液体、燃烧的熔炉、生长中的小麦、基岩等只能由模拟产生）；死亡时不能修改。被拒绝的修改会把真实方块发回客户端。
- **挖掘掉落由服务器计算**：客户端只报告“用某个工具挖掉了这个方块”，服务器按当时真实存在的方块计算掉落物，所以两个人同时挖同一个方块、或被拒绝的修改都不会多出掉落物。
- **生成实体**：点燃的 TNT 必须对应玩家刚点燃的 TNT 方块；生存模式射箭需要背包里有箭，刷怪蛋需要背包里有对应的蛋；全服有实体上限（掉落物 800、箭 300、TNT 48、生物 500），刷怪蛋在玩家附近 32 格内超过 80 个生物时被拒绝。
- **攻击**：距离 7 格内；伤害不超过快捷栏里最强武器的暴击伤害。默认关闭 PvP。
- 聊天最长 200 字，去掉颜色代码；名字只能是 1–16 个汉字、字母、数字、`_` 或 `-`。

> 物品栏由客户端模拟（合成、箱子操作都在浏览器里完成），所以这些检查用来保证正常游戏的一致性、阻止最常见的滥用，并不能完全防作弊。公共世界依靠管理员命令（踢出、封禁）和存档备份应对破坏。

## 协议

WebSocket 路径 `/webcraft/ws`。文本帧是 JSON 对象 `{ t: 类型, ... }`，二进制帧是区块数据。坐标保留两位小数、角度保留三位小数（`src/net/protocol.js` 的 `q2` / `qa`），以节省服务器上行带宽。

### 客户端 → 服务器

| t | 字段 | 说明 |
|---|---|---|
| `hello` | `v name token rd` | 握手：协议版本、名字、名字令牌、渲染距离 |
| `p` | `x y z yw pt v f s` | 位置、朝向、速度、状态标志（潜行、疾跑、飞行、着地、死亡、挥手、拉弓、进食、着火、水中）、选中的快捷栏，20 Hz（不变时不发） |
| `sub` / `unsub` | `c: [cx, cz, seq, …]` / `c: [cx, cz, …]` | 订阅 / 退订区块 |
| `e` | `x y z id [br]` | 方块修改；`br` = 生存模式挖掘所用的物品 ID（0 = 空手），由服务器计算掉落 |
| `s` | `k p v …` | 生成实体：`item`（丢出物品）、`arrow`、`tnt`、`mob`（刷怪蛋） |
| `at` | `id d kb` | 攻击实体：伤害、击退 |
| `inv` | `sl s` | 物品栏镜像（36 格）与选中格，变化时最多每 0.25 秒一次 |
| `st` | `mode dead hp` | 游戏模式、是否死亡、生命值 |
| `save` | `rec` | 完整玩家记录（`Player.serialize()`），每 10 秒及离开时 |
| `died` | `m` | 死亡信息（服务器广播） |
| `chat` | `m` | 聊天或命令 |
| `co` / `cs` / `cc` | `x y z [ch]` | 打开容器 / 修改格子（`[格, 原物品, 新物品]`，原物品不一致时冲突，服务器发回完整状态）/ 关闭 |
| `ping` | `n` | 延迟探测（每 5 秒） |
| `rd` | `rd` | 渲染距离变化 |

### 服务器 → 客户端

| t | 说明 |
|---|---|
| `welcome` / `deny` | 握手结果：玩家 ID、名字令牌、世界（名称、种子、类型、出生点）、时间、难度、管理员、玩家记录、在线玩家、欢迎语 / 拒绝原因 |
| 二进制 | 区块：`[u8 1][i32 cx][i32 cz][u32 seq][u8 类型][RLE]`，类型 0 = 未修改（客户端按种子自己生成），1 = 数据 |
| `b` | 已订阅区块的方块变化 `[x, y, z, id, …]`，每刻一批 |
| `e` / `ed` | 附近实体的状态（10 Hz，只发变化的）/ 移除：掉落物 `i`、下落方块 `f`、TNT `t`、箭 `r`、生物 `m`（格式见 `server/session.mjs` 的 `entityState`） |
| `pj` / `pl` / `pu` / `ph` | 玩家加入 / 离开 / 位置更新（10 Hz）/ 超出范围 |
| `tm` / `df` | 时间（每秒）/ 难度 |
| `fx` | 声音和粒子（按距离筛选），以及停止某个声音（苦力怕嘶嘶声） |
| `hurt` `kb` `kill` `vel` `tp` | 对本地玩家：伤害（含攻击者，用于击退方向和死亡信息）、击退、杀死、速度冲量（爆炸）、传送 |
| `give` / `invset` | 拾取或 `/give` 得到的物品 / 命令修改后的完整物品栏 |
| `mode` / `spawnpoint` / `op` | 游戏模式、重生点、管理员状态变化 |
| `chat` | 聊天消息 |
| `ct` / `cx` | 容器状态（打开时及变化时）/ 容器已关闭或被破坏 |
| `pong` | 延迟探测回复 |

## 测试

```
node --test tests/mp-server.test.js
```

在临时目录启动真实服务器，用 Node 的 WebSocket 客户端测试握手和名字认领、方块修改校验、服务器计算的掉落、TNT 与刷怪蛋校验、聊天与管理员命令，以及重启后的方块、箱子和玩家记录。

浏览器端可以用 `?mp=1&name=名字` 直接进入服务器（隐含自动化模式），配合 `tools/harness.mjs` 同时打开多个无头浏览器测试：

```
WEBCRAFT_STATIC=. WEBCRAFT_PORT=18787 WEBCRAFT_DATA=/tmp/wc WEBCRAFT_ADMIN_KEY=test node server/main.mjs
node tools/harness.mjs --url "http://127.0.0.1:18787/webcraft/?mp=1&name=A1&nomusic=1" --wait-for "window.__ready" --screenshot a.png
```
